# Controle de Alunos 💕
Marque serviços por aluno/matéria/período, com prazo, status, desconto, financeiro e cobrança.

## Publicar (GitHub Pages)
1. Crie um repositório e suba todos estes arquivos.
2. Settings > Pages > Branch: main / (root) > Save.
3. Abra o link no celular > menu do navegador > "Adicionar à tela inicial".

Dados ficam salvos no aparelho. Faça backup em Ajustes (o app avisa toda semana).
